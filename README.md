# update-dsh.cmd

双击一下，自动升级并重启 DSH。Windows 10 / 11。

## 怎么用

把文件放到任意目录，双击。

问你"确认安装/确认重启"时，输入 `Y` 回车。不输 Y 就什么都不做。

窗口里出现 `http://127.0.0.1:3080` 就打开浏览器，按一次 `Ctrl+Shift+R`。

**那个黑窗口别关**，它此时就是服务本身。

## 适合谁

在 Windows 上用 npm 全局装的 DSH（`npm i -g @deepseek-ai/dsh`）的用户。

不适合：macOS / Linux、从源码运行、只用 npx 跑的人。

## 它做了什么

找出正在跑的 DSH → 核对身份后关掉 → 装最新版 → 核对版本 → 用原端口启动 → 打印访问地址。

装完会自己检查，哪一步不对就停下，并打印一行回滚命令，复制执行就能退回旧版。

它只动程序本体，不碰你的会话和配置（都在 `~/.dsh`）。

## 技术

单文件：11 行批处理负责启动，约 240 行 PowerShell 5.1 负责干活，零第三方依赖。

一个文件两种身份——批处理跑完 11 行就让位，把文件后半段的 PowerShell 切出来执行。这样不用 `.ps1`，绕开很多电脑的脚本执行限制。

## 注意

跑的时候网页会断，正常。等地址打印出来再刷新。

装新版本约 30 秒～2 分钟；已经是最新就几秒。

超过 3 分钟还没起来，看窗口最后几行，那里会写原因或回滚命令。
